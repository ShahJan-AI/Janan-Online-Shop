# 🌸 Janan Online Shop

**Where Every Click Brings Something Beautiful.**

Janan Online Shop is a modern and responsive fashion e-commerce website designed to provide a stylish and enjoyable online shopping experience. The website features elegant designs, beautiful product collections, and a feminine color palette.

## ✨ Features

- 🏠 **Home Page** — A welcoming homepage with an attractive hero section.
- 🛍️ **Shop Page** — Explore fashion products and collections.
- 👗 **Categories** — Browse different categories of clothing and accessories.
- 💎 **Jewelry Collection** — Discover stylish jewelry and accessories.
- 👤 **Login & Registration** — User interface for account access.
- 💗 **About Us** — Learn more about Janan Online Shop.
- 📩 **Contact Us** — A dedicated contact page.
- 📱 **Responsive Design** — Designed to work across different screen sizes.
- ⭐ **Product Cards** — Product images, names, prices, ratings, and shopping buttons.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Font Awesome 4

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your browser, or use the Live Server extension.
4. Explore the website and its available pages.

## 🎯 Project Goal

The goal of Janan Online Shop is to build an attractive, user-friendly fashion shopping website while developing practical skills in front-end web development.
